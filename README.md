# Mission - Logistics(2)
## 미션 구현

### 기능 요구사항
- 출발지, 도착지, 주문자 입력 시 배송 시뮬레이션 -> 배송 완료 후 터미널로 안내 메시지 전송. 
- 출발지와 도착지, 주문자는 출발지-도착지(주문자) 와 같은 양식으로 입력 받음.
- 배송이 접수된 후 곧바로 배송이 시작되며 예측 시간의 3분당 실제 시간의 1초정도의 지연이 발생한 후 배송 완료 안내 메시지를 보낸다. 
- 이 때 구분을 위해 배송 id를 포함한다. 
- 배송 id는 배송을 구분하기 위해 존재하며 1부터 시작해서 매 배송마다 1씩 증가한다.
- (응용 1) 시뮬레이션을 비동기적으로 구현한다. 운송차량의 수는 무한하다고 가정한다.
- (응용 2) 운송차량은 5대까지 존재한다. 운용할 수 있는 차량을 넘어서는 주문이 접수될 경우 대기 후 배송한다.

### 계획
- input 수정 -> 출발지 도착지 주문자 입력을 받아야하죠 V
- 입력받은 값을 출발지, 도착지, 주문자 정보로 쪼개야하죠 V
- 쪼갠 값에서 Departure, Address에서 예외처리 해야됨
